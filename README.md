### 💰 Welth — AI-Powered Finance Platform
`Next.js` `React` `Prisma` `PostgreSQL` `Gemini AI` `Inngest`

Comprehensive financial management platform featuring automated tracking, intelligent AI insights, and background processing.

- **AI Budget Intelligence:** Architected a serverless backend using Next.js App Router, integrating Google Gemini AI for automated expense categorization and contextual financial advice.
- **Edge Security & Persistence:** Secured user data on the edge using Clerk RBAC and Arcjet bot protection; managed relational data persistence via Prisma and PostgreSQL.
- **Asynchronous Workflows:** Scheduled heavy background jobs with Inngest, ensuring reliable transactional notifications via Resend without blocking the main event loop.

### 🩺 CareConnect — Telehealth Platform
`Next.js` `React` `Prisma` `PostgreSQL` `WebRTC`

Telemedicine platform with role-specific dashboards, video consultations, and secure Edge authentication.

- **Atomic Transactions:** Engineered a credit-based appointment system using atomic Prisma transactions and Neon PostgreSQL, ensuring reliable zero-race-condition booking and refund pipelines.

- **Role-Based Access Control:** Deployed edge route guarding via Next.js Middleware and Clerk RBAC to isolate patient and doctor portal permissions.

### ⚡ Realtime AI Gym Trainer
`Python` `MediaPipe` `OpenCV` `Streamlit` `Groq LLM` `WebRTC`

Real-time computer vision and voice-coaching fitness assistant that analyzes exercise form, flags biomechanical flaws, and counts reps with sub-second feedback.

- **Pose Detection & Rep Tracking:** Built an AI real-time gym coach using MediaPipe and OpenCV for 33-point pose detection with automated rep and set counting across 5 exercises via joint angle tracking.
- **Instant AI Voice Coaching:** Integrated Groq LLM (LLaMA 3.3 70B) for real-time correctional feedback, leveraging gTTS 2.5 for sub-second spoken text-to-speech audio during workout sessions.
- **Low-Latency Vision Pipeline:** Implemented live webcam streaming using Streamlit-WebRTC with real-time skeletal overlay visualization, logging athlete workout history in SQLite.
